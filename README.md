# hooshikadev

اپ اندروید فارسی برای مدیریت مخاطبان مجاز، کشف گروه‌های عمومی مرتبط با برق و ساختمان، امتیازدهی محلی و آماده‌سازی صف پیام در روبیکا.

## چهار هسته

1. واردکردن CSV/XLSX، تشخیص ستون‌ها، یکسان‌سازی شماره‌های فارسی و عربی، حذف تکراری‌ها و ذخیره خصوصی روی گوشی.
2. ساخت جستجوهای چندعبارتی برای صفحات عمومی `rubika.ir` و رتبه‌بندی گروه‌ها و کانال‌هایی که کاربر بررسی و ذخیره می‌کند.
3. AI محلی و بدون هزینه برای سنجش ارتباط با برق، لاله‌زار، ساختمان و صنعت؛ جستجوی آنلاین با موتور جستجوی نصب‌شده روی گوشی.
4. صف پیام با فاصله زمانی دلخواه، اعلان آماده‌شدن هر نوبت و بازکردن متن در روبیکا. ثبت ارسال و رفتن به مخاطب بعدی فقط با تأیید کاربر انجام می‌شود.

برنامه از API خصوصی، مهندسی معکوس APK یا جمع‌آوری اطلاعات خصوصی استفاده نمی‌کند. روبیکا API عمومی برای پیمایش همه کاربران یا ارسال مستقیم به شماره‌ها ارائه نکرده است؛ بنابراین پیام در صفحه اشتراک‌گذاری روبیکا باز می‌شود و صاحب حساب گیرنده و ارسال را تأیید می‌کند.

## قالب فایل مخاطبان

ستون‌های رایج به‌طور خودکار شناسایی می‌شوند:

```csv
نام,شماره,رضایت,زمینه
فروشگاه نمونه,09121234567,بله,برق ساختمان
```

فایل‌های `.csv` و `.xlsx` پشتیبانی می‌شوند. حداکثر ۵۰۰۰ مخاطب معتبر در هر واردکردن نگهداری می‌شود.

## ساخت APK

نیازمندی‌ها: JDK 17، Gradle 8.9 و Android SDK 35.

```sh
gradle --no-daemon testDebugUnitTest assembleDebug
```

خروجی در `app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود. Workflow گیت‌هاب نیز Artifact با نام `hooshikadev-debug` تولید می‌کند.
