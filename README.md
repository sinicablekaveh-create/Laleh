# Telegram Electric

اپ اندروید برای ورود به حساب تلگرام با TDLib و بانک آفلاین واژه‌های مرتبط با برق.

## امکانات

- ورود با API ID و API Hash خود کاربر
- ورود شماره تلفن، کد تلگرام و رمز دومرحله‌ای
- افزودن و فعال‌سازی پروکسی MTProto و SOCKS5 با پیست لینک از Clipboard
- بانک اولیه واژه‌های برق فارسی و انگلیسی
- جست‌وجوی آفلاین واژه‌ها
- افزودن دستی واژه
- یادگیری محلی واژه‌های جدید از پیام‌هایی که به واژه‌های برق نزدیک هستند
- ساخت APK با GitHub Actions

## حریم خصوصی

API Hash و شماره تلفن داخل Repository ذخیره نمی‌شوند. این اطلاعات هنگام اجرا داخل برنامه وارد می‌شوند. بانک واژه نیز روی گوشی ذخیره می‌شود.

## APK

Workflow فایل `.github/workflows/build-apk.yml` روی هر Push مرتبط، نسخه Debug را می‌سازد و Artifact با نام `telegram-electric-debug` منتشر می‌کند.

## نسخه 1.11.0

- تشخیص دقیق عضویت: گروه ترک‌شده، مسدودشده و عضو محدودِ خارج از گروه در گروه‌های حساب نمایش داده نمی‌شود.
- اطلاعات چت‌ها، گروه‌های پایه و سوپرگروه‌ها از Cache به‌روز TDLib خوانده می‌شود؛ جستجو برای هر نتیجه درخواست جداگانه دریافت اطلاعات نمی‌فرستد.
- تغییر عضویت، مدیریت و تعداد اعضا با Updateهای TDLib در فهرست گروه‌ها اعمال می‌شود.
- Updateهای یکسان باعث بازسازی صفحه و ذخیره‌سازی تکراری نمی‌شوند و نمایش نتایج جستجو به‌صورت تجمیعی تازه می‌شود.
- کپی عکس و تولید خروجی TXT/Excel روی Thread جدا انجام می‌شود؛ عکس قبلی تا تکمیل کپی عکس جدید حفظ می‌شود.
- انتخاب نوع و بازه خروجی هنگام بازسازی Activity حفظ می‌شود.

در نسخه 1.11.0 ارسال زمان‌بندی‌شده به مدیران و مالکان عضو محدود بود؛ این محدودیت در نسخه 1.12.0 با کنترل مجوز واقعی ارسال جایگزین شده است.

تست‌های بازگشت با `gradle testDebugUnitTest` اجرا می‌شوند و پیش از ساخت APK در GitHub Actions بررسی می‌شوند. تست نصب، ورود واقعی تلگرام و عملکرد روی گوشی باید جداگانه انجام شود.

## نسخه 1.12.0

- زیر «گروه‌های هدف»، دکمه «انتخاب گروه هدف» فهرست گروه‌های عضو حساب را باز می‌کند؛ انتخاب‌ها روی گوشی حفظ می‌شوند.
- فهرست اصلی و آرشیو حساب به‌صورت صفحه‌بندی‌شده با `loadChats` بارگذاری می‌شوند. گروه‌های کشف‌شده‌ای که حساب عضو آن‌ها نیست، هدف ارسال نمی‌شوند.
- عضو عادی هم با مجوز واقعی Telegram می‌تواند ارسال کند. مجوز متن و عکس و محدودیت شخصی اعضا جداگانه کنترل می‌شود و تغییر مجوزها بلافاصله اعمال می‌شود.
- ساخت پیام عکس با ساختار `InputPhoto` نسخهٔ نصب‌شدهٔ TDLib سازگار شده است.
- START هسته را فعال می‌کند؛ حتی بدون متن یا گروه هدف، جستجوی بانک واژه ادامه دارد. ارسال فقط با متن و گروه انتخاب‌شدهٔ مجاز انجام می‌شود.
- هنگام اجرای هسته، دکمه START به «ثبت تنظیمات» تبدیل می‌شود تا متن جدید ثبت شود. STOP ارسال‌ها و جستجوهای بعدی را متوقف می‌کند و پاسخ دیررس درخواست قبلی وضعیت توقف را تغییر نمی‌دهد.
- ثبت تنظیمات و تغییر فاصلهٔ ارسال، زمان ارسال تعیین‌شده یا انتظار اجباری Telegram را لغو نمی‌کند؛ فاصلهٔ جدید برای چرخهٔ بعدی اعمال می‌شود. گروه انتخاب‌شده‌ای که مجوزش تغییر کرده، همچنان قابل برداشتن از انتخاب است.

منابع رسمی: [TDLib](https://github.com/tdlib/td)، [loadChats](https://core.telegram.org/tdlib/docs/classtd_1_1td__api_1_1load_chats.html)، [مجوزهای چت](https://core.telegram.org/tdlib/docs/classtd_1_1td__api_1_1chat_permissions.html).

## جستجوی شماره و مدیریت بانک واژه

این به‌روزرسانی با نسخهٔ `1.13.0` و `versionCode = 15` ساخته می‌شود.

در بخش مخاطبین هسته مرکزی، شماره را وارد و «جستجوی شماره» را انتخاب کنید. برنامه پس از کنترل ورود و اتصال، درخواست واقعی `searchUserByPhoneNumber` را به TDLib می‌فرستد و نام، شناسه و شمارهٔ مخاطب پیدا‌شده را نمایش می‌دهد. «دریافت مخاطبین تلگرام» نیز با `getContacts` فهرست مخاطبین حساب را دریافت می‌کند. این عملیات مخاطب جدیدی به حساب اضافه نمی‌کند و به مجوز دفترچه تلفن اندروید نیاز ندارد.

فرمت‌های `+98912…`، `98912…`، `0098912…`، `0912…` و `912…` و ارقام فارسی و عربی پشتیبانی می‌شوند. شمارهٔ محلی موبایل ایران به `+98` تبدیل می‌شود؛ شماره‌های محلی سایر کشورها باید با کد کشور وارد شوند. پیدا نشدن شماره با پاسخ 404 ممکن است ناشی از نداشتن حساب یا تنظیمات حریم خصوصی تلگرام باشد. برنامه شماره‌های مخفیِ کاربران ناشناس را استخراج نمی‌کند؛ در جستجوی موفق، شماره‌ای که خود کاربر وارد کرده نیز می‌تواند همراه نتیجه ذخیره شود.

بانک واژه، افزودن، ویرایش و حذف را همراه با اعتبارسنجی و ذخیره روی گوشی فراهم می‌کند. فهرست صفحه‌بندی شده است و کنار هر واژه دکمه‌های ویرایش و حذف قرار دارد. حذف واژه‌های اولیه پس از اجرای مجدد حفظ می‌شود و یادگیری خودکار، واژهٔ حذف‌شده را برنمی‌گرداند؛ افزودن دستی آن همچنان ممکن است.

برای جستجوی بانک، تعداد مراحل و حداقل طول بخش پایانی را تنظیم و جستجو را شروع کنید. پیش‌فرض پنج مرحله و حداقل سه حرف است. هر مرحله یک درخواست واقعی `searchPublicChats` دارد؛ برای نمونه:

```text
برق ساختمان → برق ساختما → برق ساختم → برق ساخت → برق ساخ
صنعت ساختمان → صنعت ساختما → صنعت ساختم → صنعت ساخت → صنعت ساخ
```

واژه‌ها به ترتیب، هرکدام مستقل تا حد تعیین‌شده پردازش می‌شوند و اجرای جستجو پس از پایان کل بانک کامل می‌شود. توقف، ادامه و شروع دوباره از ابتدا در صفحه بانک در دسترس است. نتیجهٔ هر تلاش با واژهٔ اصلی، عبارت مرحله، زمان، موفقیت یا خطا، تعداد گروه‌ها و شناسهٔ نتایج ذخیره می‌شود و تاریخچه صفحه‌بندی دارد. مرحلهٔ قطع‌شده پس از ادامه دوباره اجرا می‌شود. تنظیمات جدید، مراحل بانک را از ابتدا تنظیم می‌کند و تاریخچهٔ قبلی را نگه می‌دارد.

داده‌ها در `SharedPreferences` خصوصی موجود برنامه ذخیره می‌شوند: `electrical_word_bank` برای بانک و حذف‌ها، `smart_search_queue` برای تنظیمات، پیشرفت و تاریخچه، و `telegram_discovery` برای نتایج مخاطبین و گروه‌ها. نشست و پایگاه دادهٔ تلگرام همچنان توسط TDLib در پوشهٔ خصوصی `tdlib` مدیریت می‌شوند.

لاگ تشخیصی جستجو با نام `Laleh.TelegramSearch`، شناسهٔ درخواست، نوع عملیات، وضعیت اتصال و کد خطا را ثبت می‌کند و شماره را از جزئیات خطا حذف می‌کند. هر درخواست جستجو مهلت ۳۰ ثانیه‌ای و پاسخ نهاییِ یک‌بار دارد. خطاهای اتصال، نشست، پاسخ نامعتبر و محدودیت موقت تلگرام در رابط کاربری و تاریخچه قابل بررسی هستند.

برای بررسی محلی با JDK 17 و Android SDK 35:

```sh
gradle --no-daemon testDebugUnitTest assembleDebug
```

تست‌های واحد، انتقال شماره به درخواست واقعی TDLib را با پاسخ‌های کنترل‌شده، ماندگاری بانک و تاریخچه، مراحل جستجو و رفتار توقف بررسی می‌کنند. تأیید پاسخ واقعی سرور و رابط روی گوشی نیازمند نصب APK و ورود به حساب تلگرام است.
